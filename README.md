# Pizza App (Frontend, React)

**Technologies:** React · JavaScript (ES6+) · Bootstrap 5 · React Router · Webpack

---

## Overview
Pizza App is a **React-based frontend application** built as part of the Modsen internship.  
It allows users to browse pizzas, customize orders, and simulate a shopping cart experience, interacting with the backend API.

This project represents the **client-side interface** of the system that also includes the [Pizza App Backend](https://github.com/FedorDevelopmer/Practice_Modsen).

---

## Features
- 🍕 Interactive pizza catalog with filtering and search  
- 🛒 Shopping cart  
- 📱 Responsive design with Bootstrap 5  
- 🔄 Navigation via React Router v6  

---

## ⚙️ Tech Stack

| Layer | Stack |
|-------|--------|
| **Framework** | React 18 |
| **UI Components** | React-Bootstrap, Bootstrap 5 |
| **Routing** | React Router DOM |
| **Testing** | Jest, React Testing Library |
| **Build Tools** | Webpack 5, React Scripts |
| **Linting & Config** | ESLint (React App preset) |
| **Building and Deployment** | NPM v10.7.0, Node.js v20.14.0 |

---

## Available Scripts

```bash
# Start the development server
npm start

# Build for production
npm run build

# Eject configuration
npm run eject
```

> For local development, make sure the backend (Pizza App Backend) is running before starting the frontend to enable full API interaction.
